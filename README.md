# FortYours OS

Sistema operativo de escritorio de AJVALENZ basado en ReactOS. Beta gratuita en desarrollo activo.

- [FortYours OS 1.93 Beta · Revisión UEFI y código fuente](https://github.com/laliguajpv/FortYours-OS/releases/tag/v1.93-r2)
- [Página oficial y descargas](https://ajvalenz.cl/os/)

Hay dos ediciones para máquinas virtuales. Usa UEFI de 64 bits para la edición actualizada o BIOS heredada de 32 bits para la otra edición.

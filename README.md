# FortYours OS

Sistema operativo de escritorio de AJVALENZ basado en ReactOS. Beta gratuita en desarrollo activo.

- [Página oficial y descargas](https://ajvalenz.cl/os/)
- [ISO y paquetes de código fuente](https://github.com/laliguajpv/FortYours-OS/releases)

La versión 1.93 ofrece ediciones separadas para UEFI de 64 bits y BIOS heredada de 32 bits. Ambas se probaron en modo Live en máquinas virtuales.
